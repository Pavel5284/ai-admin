## Проверка секретов

```bash
git ls-files | grep -E '^\.env$'
git log --all --full-history -- .env
```

Обе команды должны ничего не вывести. `.env` существует локально, но не должен попадать в git.

## Что осталось сделать владельцу

1. Получить `TELEGRAM_BOT_TOKEN` у BotFather и проверить `npm run dev` в Telegram.
2. Собрать и запустить бота в Docker: `docker compose --profile bot up -d --build`, затем `docker compose --profile bot exec bot npm run kb:load`.
3. Записать видео по `docs/video.md` и добавить ссылку в README.
4. Передать 20 holdout-сценариев (чужие формулировки) и один раз прогнать `npm run eval -- holdout`.
5. Создать GitHub-репозиторий, проверить отсутствие секретов и сделать первый push.
6. Обновить резюме и проговорить ответы на восемь вопросов.
7. Для продакшена проверить лимиты провайдера и при необходимости задать отдельные `LLM_STYLE_MODEL`/ключ для стиля; иначе под нагрузкой стиль будет чаще откатываться в шаблон.
